# Графика прототипа (меняется независимо)

Каждый кусок — отдельный файл, путь прописан в index.html в объекте ART. Замена картинки = подмена файла или одной строки в ART.

Нужно (сейчас плейсхолдеры в коде):
- bg/room.png      — фон комнаты (Дом, Гардероб, Мой мишка)
- bg/world.png     — фон карты (Мир)
- bear/base.png    — мишка без одежды, одна поза и камера
- bear/hoodie.png  — мишка в худи+кедах
- bear/sundress.png— мишка в сарафане+ботинках
- items/*.png      — карточки вещей (худи, кеды, сарафан, ботинки)

Пока файла нет — экран показывает цветной плейсхолдер, РАЗНЫЙ для каждого образа. Код работает без картинок.
