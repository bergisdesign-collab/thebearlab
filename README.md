# BearLab — мастерская мишки

Совместный демонстрационный прототип Димы и Ильи. Один вход — `index.html`: рисованный персонаж, оригинальная 3D-мастерская, гардероб, мир, «три в ряд» и локальная заявка для обсуждения с производством. Основная игра и её GDD ведутся отдельно.

## Пройти демонстрацию

1. На Доме нажмите **Одеть**. Выберите образ, снимите или добавьте отдельную вещь. **Готово — мой образ → В корзину** сохраняет эту комплектацию. В режиме Студии тот же путь начинается с Гардероба.
2. Вернитесь и соберите второго мишку. У первого не меняются одежда, цена и снимок. Количество и удаление доступны в корзине.
3. **К доставке**: выберите пункт выдачи или курьера, заполните учебные поля и нажмите **Создать заявку**. Данные формы никуда не отправляются; в заявке сохраняется способ получения.
4. **Открыть заявку** показывает одежду, обувь, аксессуары и 13 шагов сборки. **Скачать JSON** скачивает настоящий файл. **Заявки → Импорт JSON** открывает его в другом браузере.
5. **Играть** или **Исследовать → Игровой клуб**: выбирайте соседние фишки, собирайте линии от трёх, используйте подсказку. После 12 результативных ходов откроется результат и начислится локальная награда. Рекорды локальные.

Первый вход открывает игровой режим по референсу №9: сцена, крупный мишка, четыре основных действия и пять разделов. **Кормить** повышает сытость, нажатие на мишку — настроение; профиль показывает состояние и отдых. **Награды** выдаёт один приветственный подарок. **Задания** связывает заботу, примерку и исследование, с однократной наградой. Коллекция, событие, магазин и рюкзак открываются поверх текущей сцены. Никаких покупок за реальные деньги и сервера нет.

Кнопка **⚙** открывает настройки: Студия / Игровой, 2D / 3D, анимации, имя, размер и карта всех 13 экранов. **Изменить мишку** открывает мастерскую Димы с деталями, цветами, позами и аксессуарами. Её кнопки корзины и производства ведут в общий маршрут. Настройки и комплектация сохраняются на устройстве.

В 2D базовые образы используют иллюстрацию. После изменения геометрии, цвета или аксессуаров показывается снимок фактической модели. Снимок нестандартного мишки сохраняется внутри JSON. Для старой заявки без снимка нестандартной модели показывается подпись, а точные параметры остаются в составе.

Цены, доставка и артикулы — демонстрационные. Физическую изготовимость подтверждает производство. Оплаты и отправки заказа нет. Для обмена между устройствами нужен JSON; общей серверной базы нет. Внешний GLB подходит для локальной примерки, в передаваемой заявке используются встроенные модели. Иллюстрации созданы ИИ: **проба, не утверждено**.

## Запуск и проверки

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8000/. Внешние зависимости для запуска не нужны: three.js r147, модель и изображения лежат локально. После первого успешного открытия service worker сохраняет ресурсы для офлайн-работы.

```sh
node --test tests/order-model.test.cjs tests/match3.test.cjs
```

Браузерные проверки требуют Playwright и Chromium:

```sh
npm install --no-save --package-lock=false playwright@1.63.0
npx playwright install chromium
node tests/browser/run.cjs
```

Runner поднимает собственный локальный сервер и завершает его после проверки. `BEARLAB_BASE_URL` позволяет проверять уже запущенную сборку; `BEARLAB_CHROME` задаёт путь к Chromium; `BEARLAB_PLAYWRIGHT` — путь к установленному модулю. Скриншоты и результаты сохраняются вне репозитория, в системном временном каталоге `bearlab-demo-qa` или в `BEARLAB_QA_DIR`.

Проверяются 360×640, 390×844, горизонтальный 844×390 и desktop 1440×900/1000: игровая композиция, уход, однократные награды, сохранение прогресса, гардероб, карта, полный раунд, переключение в студию; отдельно — две комплектации, количества, доставка, экспорт/импорт в чистый контекст, настройки, 3D, некорректный JSON/код, отказ clipboard и офлайн. Это браузерные размеры, а не испытание на физических телефонах.

## Совместная работа

Одна задача — одна ветка и PR. Ссылка на основную версию https://bergisdesign-collab.github.io/thebearlab/ соответствует `main`; демонстрация ветки указывается отдельно в PR. Агенты не объединяют PR без согласования владельца.

| Файл | Назначение |
| --- | --- |
| `index.html` | Мастерская, 3D, маршруты 13 экранов, игра, интеграция общего состояния |
| `sandbox/studio-ui.js`, `sandbox/studio-ui.css` | Студия, общие иллюстрации, адаптация, настройки |
| `sandbox/game-ui.js`, `sandbox/game-ui.css` | Игровой слой по референсу №9, локальный питомец, награды, диалоги, гардероб и карта |
| `GAME_VISUAL_CONTRACT.md` | Композиция, критерии визуальной приёмки, источники и границы |
| `sandbox/bear-preview.js` | Снимок реальной модели для нестандартной комплектации |
| `sandbox/order-model.js` | Неизменяемые заявки, валидация, совместимость, JSON и хранение |
| `sandbox/workshop.css` | Оригинальная мастерская Димы |
| `sandbox/order-ui.js`, `sandbox/order-ui.css` | Сохранённый первоначальный интерфейс демозаявок |
| `PROTOTYPE_SPEC.md` | Текущий контракт экранов и поведения |
| `tests/` | Проверки модели, игры и браузерных маршрутов |
| `assets/demo/` | Рисованные персонаж и мир — проба, не утверждено |
| `teddy.json`, `vendor/three-r147/`, `sw.js` | Встроенная модель, локальная библиотека и офлайн-кэш |

Каталоги `bot/` и `worker/` — отдельные сервисы; эта демонстрация их не использует.
