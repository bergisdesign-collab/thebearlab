# TheBearLab — мастерская мишек

Веб-приложение (PWA) для создания индивидуального плюшевого мишки в 3D с последующим заказом пошива.

## Что умеет
- 3D-мишка с ворсом и скелетом из 15 костей: голова, уши, руки, ноги, хвост
- Настройка цвета, узора, ворса, глаз, бровей, пропорций, позы
- 14 аксессуаров, закреплённых на костях
- 8 анимаций: помахать, танец, прыжок, кружиться, обнимашки, хлопать, поклон, уснуть
- Строка «Хочу…»: текстовое описание превращается в мишку
- Детский и мастер-режим, отмена действий, код мишки для обмена
- Мобильная версия с нижней панелью, установка на экран телефона, работа офлайн

## Запуск
Статический сайт без сборки. Локально:
```
python3 -m http.server 8000
```
и открыть http://localhost:8000. Через `file://` модель не загрузится.

GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Файлы
- `index.html` — приложение (three.js r147 с CDN jsDelivr)
- `teddy.json` — 3D-модель с костями (GLB в base64)
- `assets/teddy-rigged.glb` — та же модель в GLB, `assets/teddy-source.glb` — исходник
- `manifest.webmanifest`, `sw.js`, `icon-*.png` — PWA
- `#debug` в конце адреса включает диагностику и повтор анимаций
