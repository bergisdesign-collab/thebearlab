# TheBearLab — мастерская мишек

Совместная песочница Димы и Ильи для примерки идей и показа производству. Можно собрать мишку в 3D и пройти путь покупателя до демонстрационного листа сборки. Игровые сценарии и продуктовые решения для основной игры команда ведёт отдельно.

## Пройти сценарий

1. В мастерской выберите встроенную модель, настройте мишку и добавьте аксессуар. Перетащите модель, чтобы посмотреть её с другой стороны.
2. Нажмите **«В корзину»**. Для сравнения двух комплектаций вернитесь в мастерскую, измените мишку и добавьте его ещё раз. В корзине можно поменять количество и удалить позицию.
3. Нажмите **«Выбрать доставку»**, выберите учебный пункт выдачи или курьера, затем **«Создать демозаявку»**.
4. В карточке проверьте комплект, количество, сумму, способ получения, 13 шагов сборки и отдельный список аксессуаров. Вкладка **«Производство»** открывает журнал; кнопка **«Открыть пример»** подходит для быстрого показа на встрече.

Цены, доставка и артикулы служат для обсуждения. Реальные SKU и возможность изготовления подтверждает фабрика. Оформление сохраняет снимок конфигурации в браузере и не вызывает оплату или отправку заказа.

### Передать заявку коллеге

В карточке нажмите **«Скачать JSON»**, передайте файл второму участнику, затем на его устройстве откройте **«Производство» → «Импорт из JSON»**. Илья и Дима увидят одинаковый состав, количество и сумму. Повторный импорт идентичного файла не создаёт дубликат. Корзина и журнал сохраняются локально для адреса сайта и профиля браузера; при очистке данных сайта их удаляет браузер. Для повторного показа храните файл заявки. Внешний 3D-файл доступен для локальной примерки; для передаваемой заявки используйте встроенного мишку.

## Запуск и проверка

Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [мастерскую на этом компьютере](http://127.0.0.1:8000/). Для загрузки модели нужен HTTP. Страница использует локальную копию three.js r147 и не требует установки npm-пакетов. Адрес [основной версии проекта](https://bergisdesign-collab.github.io/thebearlab/) соответствует ветке `main`; версия конкретной идеи определяется её веткой или коммитом.

Проверка модели заказов (Node.js 18+):

```sh
node --test tests/order-model.test.cjs
```

Для проверки интерфейса пройдите сценарий выше на компьютере и на ширине телефона, обновите страницу и откройте JSON на другом устройстве или в отдельном профиле браузера.

## Как менять вместе

- На одну идею заведите короткую ветку от актуального `main`, например `exp/pickup-first`. Откройте её в Claude Code или Codex и попросите одну конкретную правку: «В оформлении покажи пункт выдачи первым. Проверь выбор курьера на телефоне».
- Поделитесь pull request с коллегой. Укажите, какой экран открыть, что проверить и как увидеть версию ветки. Если подключён предпросмотр, приложите его ссылку. Если нет, второму участнику достаточно переключиться на ветку и запустить мастерскую локально.
- В PR зафиксируйте решение. Принятый вариант объедините с `main`, отложенный PR можно закрыть. Для отмены уже принятой идеи создайте обратный PR через **Revert**.

## Устройство проекта

| Где | Что менять |
| --- | --- |
| `index.html` | 3D-сцена, параметры мишки, режимы мастерской, позы, анимации, подключение корзины |
| `sandbox/workshop.css` | Верхняя панель, компоновка мастерской и адаптация под телефон |
| `sandbox/order-ui.js`, `sandbox/order-ui.css` | Кнопки, экраны корзины, доставки и журнала, импорт и скачивание |
| `sandbox/order-model.js` | Каталог, состав, количество, доставка, версия формата, валидация и хранение заявок |
| `tests/order-model.test.cjs` | Проверки модели, совместимости JSON и повторного импорта |
| `teddy.json`, `assets/`, `sandbox/bear-reference.webp` | 3D-модель с костями, исходные GLB и изображение для режима без 3D |
| `vendor/three-r147/`, `manifest.webmanifest`, `sw.js` | Локальные зависимости, установка PWA и кэш ресурсов |

Каталоги `bot/` и `worker/` относятся к отдельным сервисам. Для запуска мастерской достаточно статических файлов.
