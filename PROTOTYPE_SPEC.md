# BearLab — контракт демонстрационного прототипа

Версия поведения от 23 ноября 2026. Это спецификация фронтенд-прототипа, не утверждение решений основной игры. Единый вход — `index.html`.

## Общие данные и представления

Мастерская Димы, гардероб и оформление используют один `cfg`. Добавление в корзину сохраняет отдельную комплектацию и цену; последующие изменения редактора не меняют её. Одежда хранится снимком каталога, аксессуары — отдельными слоями. Артикулы демонстрационные.

По умолчанию включены спокойная Студия и 2D-иллюстрация. Игровой стиль меняет оформление, а 3D — представление персонажа. Для нестандартных формы, цвета, аксессуаров и футболки используется снимок фактической модели. В новом заказе этот снимок передаётся вместе с JSON. Отсутствие исторического снимка не заменяется изображением другого мишки.

На телефоне нижняя навигация присутствует на хабах Дом, Гардероб, Мир, Игры. Выбор хаба очищает стек текущего сценария. На компьютере есть постоянная боковая навигация. Кнопка назад внутри сценария сохраняет выбор; мастерская возвращает в экран, из которого её открыли.

## Экраны

| Экран | Действия и результат |
| --- | --- |
| Дом | Угостить — реакция. Изменить мишку — оригинальная мастерская. Навигация — гардероб, мир и игра. |
| Мастерская | Детали, цвета, модели, одежда, аксессуары, позы, отмена/повтор, сброс с подтверждением, код. В корзину сохраняет комплектацию в общем маршруте. Производство открывает Заявки. |
| Гардероб | Три комплекта и отдельные вещи; снятая обувь исчезает из рисунка и состава. Посмотреть образ открывает Мой мишка. |
| Мой мишка | Текущий образ, цена и одежда. В корзину добавляет снимок. Поделиться открывает код. |
| Корзина | Количество, удаление, сумма, вход в Заявки. Пустая или повреждённая корзина не допускается к доставке. |
| Доставка | Пункт выдачи или курьер. Имя и телефон обязательны; для курьера нужен адрес. Создать заявку сохраняет локальный заказ. |
| Подтверждение | Номер и состав созданной заявки; Открыть заявку ведёт к листу сборки. |
| Заявки | Список сохранённых заказов, открытие листа, импорт JSON из поля. Повтор одинакового файла не создаёт дубликат; повреждённый файл показывает ошибку. |
| Лист сборки | Основа, одежда и обувь со SKU и шт./пара, отдельные аксессуары, 13 раскрываемых шагов с описаниями. Скачать JSON загружает файл. |
| Поделиться | Скопировать код BEAR-, вставить и применить код. При запрете clipboard код выделяется для ручного копирования и показывается ошибка. |
| Мир | Иллюстрированная карта с входами в мастерскую, гардероб и игру. |
| Игра | Поле 6×7, соседний обмен, линии от трёх, каскады, очки, 12 результативных ходов, подсказка и перезапуск. Неверный обмен возвращает обе фишки и не тратит ход. Нет допустимого хода — перемешивание. |
| Результат | Счёт, пять локальных рекордов. Ещё раз начинает новую партию; Домой возвращает на Дом. |

## Настройки

⚙ открывает доступную с каждого экрана панель. Работают Студия/Игровой, 2D/3D, анимации, имя (до 10 символов), размер 20/30/45 см и карта 13 экранов. Переход к доставке требует корзины, к подтверждению и листу — созданной заявки. Выборы сохраняются локально. Если WebGL недоступен, 3D не включается и выводится сообщение.

## Хранение и пределы демонстрации

Комплектация, корзина, журнал, настройки и рекорды сохраняются в браузере. Очистка данных сайта удаляет их. JSON переносит заявку в другой браузер; серверной синхронизации нет. Поля контактной формы учебные, никуда не отправляются и не сохраняются в JSON. Пользовательский GLB остаётся локальной примеркой и не может входить в передаваемый заказ.

Проверки формата и происхождения снимков не означают подтверждения производством. Оплаты, платных наград и настоящего заказа нет. Иллюстрации — «проба, не утверждено».

## Приёмка

- Две разные комплектации, изменение текущей не меняет первую; снятие обуви, количество и удаление.
- Оба способа доставки, обязательные поля, создание, лист, аксессуары, reload, реальный файл JSON и чистый импорт со снимком.
- Мир → мастерская → назад; игра до нуля ходов → результат → новая игра. Подсказки не меняют поле.
- Все настройки, действительный 3D в рамке персонажа и возврат в мастерскую; действительный код и ошибки JSON/кода/clipboard.
- Размеры 360×640, 390×844, 1440×1000; отсутствие ошибок JS; офлайн после первого успешного открытия.
- Свидетельства: автоматические проверки `tests/`, скриншоты и JSON-отчёты вне репозитория. Реальные устройства и физическое изготовление требуют отдельной проверки.
